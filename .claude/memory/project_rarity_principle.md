# Rarity Scoring — Core Product Principle

## The Insight
Every additional measurable iris trait makes each person's eyes MORE rare, not just more described.
Color alone: maybe 1 in 50 share your exact shade.
Color + heterochromia type: 1 in 200.
Add limbal ring strength + sectoral position + freckle pattern: the combination becomes effectively unique.
The more specific the measurement, the rarer every eye becomes — because probability is multiplicative across traits.

## Strategic Implication
Rarity scoring is a growth mechanism: as we add more measurable traits, existing users' scores
can be recalculated and will almost always go UP. That's a re-engagement hook.

## Traits Currently Measured
- Eye color category + specific name
- Heterochromia (warmth gradient, lightness gradient, true central)
- Limbal ring (strength + color)
- Sectoral heterochromia (presence + clock position)
- Iris freckles (count + positions)
- Brightness + saturation character

## Traits to Add (future — increases specificity)
- Stroma texture / fiber pattern (Rayid: Stream, Jewel, Flower, Shaker — partially wired)
- Collarette shape and prominence
- Crypt density
- Pupil shape irregularity
- Limbal ring color gradient (not just presence)
- Iris asymmetry between left and right beyond bilateral heterochromia

## Copy Principle
Never sell just the color. Always emphasize the COMBINATION.
"It's not that your eyes are a rare color — it's that this exact combination of color,
inner ring, limbal border, and markings has never appeared in exactly this way before."

Goal: every single person should finish the analysis feeling like their eyes are genuinely special —
because at enough specificity, they are.
